## About the project
The final solution to the "Professionals" championship case in the "Software Solutions for Business" competency. The project includes the full development cycle of a business application: desktop client, web service, API, component library, and testing.

## Purpose of creation
Preparation for and participation in the "Professionals" championship finals. The repository contains the solution to the competition task, divided into modules according to the competency requirements.

## Project structure
- **Desktop** — desktop application 
- **WEB-Service** — web service
- **API** — software interface for interaction between modules
- **Библиотека** — Python library written to order
- **Тестирование** — tests
- **Интеграционное тестирование** — checking the interaction of modules
- **Импорт** — data for import into the database
- **Документы** — accompanying documentation
- **Задание** — terms of the competition case

## Technology stack
- Python 3
- PyQt 
- Flask 
- PostgreSQL
