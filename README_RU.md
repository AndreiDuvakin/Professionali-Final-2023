## О проекте
Финальное решение кейса чемпионата «Профессионалы» по компетенции **«Программные решения для бизнеса»**. Проект включает полный цикл разработки бизнес-приложения: десктопный клиент, веб-сервис, API, библиотеку компонентов и тестирование.

## Цель создания
Подготовка и участие в финале чемпионата «Профессионалы». Репозиторий содержит решение конкурсного задания, разбитое по модулям в соответствии с требованиями компетенции.

## Структура проекта
- **Desktop** — настольное приложение 
- **WEB-Service** — веб-сервис
- **API** — программный интерфейс для взаимодействия модулей
- **Библиотека** — библиотека Python написанная по заданию
- **Тестирование** — тесты
- **Интеграционное тестирование** — проверка взаимодействия модулей
- **Импорт** — данные для импорта в БД
- **Документы** — сопроводительная документация
- **Задание** — условия конкурсного кейса

## Стек технологий
- Python 3
- PyQt 
- Flask 
- PostgreSQL
